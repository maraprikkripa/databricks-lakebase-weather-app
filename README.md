# Databricks Lakebase Weather App

A weather data application built on Databricks with Lakebase (PostgreSQL + pgvector).

## Overview

This application:
- Fetches weather data from a weather API
- Stores data in Lakebase (Databricks-managed PostgreSQL)
- Provides a Flask API for querying weather information
- Uses vector embeddings for semantic weather pattern search

## Features

- Real-time weather data ingestion
- Historical weather data storage
- Vector search for similar weather patterns
- RESTful API endpoints
- Scheduled data updates via Databricks workflows

## Tech Stack

- **Backend**: Flask (Python)
- **Database**: Databricks Lakebase (PostgreSQL + pgvector)
- **Orchestration**: Databricks Workflows
- **Deployment**: Databricks Apps
- **Vector Search**: sentence-transformers
